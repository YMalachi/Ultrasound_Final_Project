# Ultrasound Imaging Simulation with Field II

MATLAB project for simulating ultrasound transducers, beam focusing, and pulse-echo B-mode imaging using the Field II toolbox.

## Project Contents

- `simulateConcaveTransducerField.m`  
  Simulates the acoustic field of a concave transducer.

- `analyzeLinearArrayFocusing.m`  
  Analyzes focusing behavior in a linear ultrasound array.

- `simulatePulseEchoBModeImaging.m`  
  Simulates pulse-echo acquisition and B-mode image formation.

- `computeTransmitDelays.m`  
  Calculates transmit delays for array focusing.

- `convertFieldToDecibels.m`  
  Converts simulated field values to a logarithmic decibel scale.

## Requirements

- MATLAB
- Field II toolbox
